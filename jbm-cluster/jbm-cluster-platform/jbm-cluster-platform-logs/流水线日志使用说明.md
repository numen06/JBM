# 流水线样式日志使用说明

## 📋 功能说明

`BusinessLogPipelineTest` 演示了如何像CI/CD流水线那样记录分步骤的日志：

### 功能特点

1. **分步骤记录** - 每个步骤独立记录日志
2. **实时输出** - 步骤执行过程中实时追加日志
3. **步骤摘要** - 显示每个步骤的执行时间
4. **按步骤查看** - 可以查看某个步骤的日志（类似界面点击步骤）
5. **完整日志** - 支持查看整个流水线的完整日志

### 类似界面功能

```
┌─────────────────────────────────────────────────────────┐
│  左侧：步骤列表            │  右侧：当前步骤日志        │
├───────────────────────────┼───────────────────────────┤
│ ✓ 申请运行环境(0s)        │  [executionStep begins...] │
│ ✓ 清理工作区(1s)  ←选中   │  [INFO] 开始清理工作区... │
│ ✓ 克隆代码(5s)            │  [INFO] 清理完成!          │
│ ✓ 流水线缓存(4s)          │  [SUCCESS] 执行命令成功    │
│ ✓ feige-manager(33s)      │                            │
│ ✓ 缓存上传(0s)            │  [查看原始日志] [下载日志] │
└───────────────────────────┴───────────────────────────┘
```

## 🚀 使用示例

### 示例1：构建流水线

```java
// 1. 创建流水线日志
Map<String, Object> params = new HashMap<>();
params.put("module", "CI/CD流水线");
params.put("operation", "构建流水线");
params.put("content", "流水线开始...");
params.put("autoTimestamp", true);

String logId = createLog(params);

// 2. 记录各个步骤
logStep(logId, "申请运行环境", () -> {
    appendLogLine(logId, "[INFO] 开始申请运行环境...");
    appendLogLine(logId, "[INFO] 分配容器: container-001");
    appendLogLine(logId, "[SUCCESS] 申请运行环境成功");
});

logStep(logId, "清理工作区", () -> {
    appendLogLine(logId, "[INFO] 开始清理工作区...");
    appendLogLine(logId, "[INFO] 清理完成!");
    appendLogLine(logId, "[SUCCESS] 执行命令成功");
});

// 3. 查看某个步骤的日志
List<Map<String, Object>> stepLogs = getLogByLineRange(logId, startLine, endLine);
```

### 示例2：部署流水线

```java
String logId = createLog(params);

// 步骤1：备份
logStep(logId, "备份当前版本", () -> {
    appendLogLine(logId, "[INFO] 备份文件: app-v1.0.0.tar.gz");
    appendLogLine(logId, "[SUCCESS] 备份完成");
});

// 步骤2：停止服务
logStep(logId, "停止服务", () -> {
    appendLogLine(logId, "[INFO] 停止进程: PID 12345");
    appendLogLine(logId, "[SUCCESS] 服务已停止");
});

// 步骤3：部署新版本
logStep(logId, "部署新版本", () -> {
    appendLogLine(logId, "[INFO] 上传文件: app-v1.0.1.jar");
    appendLogLine(logId, "[SUCCESS] 部署完成");
});

// 步骤4：启动服务
logStep(logId, "启动服务", () -> {
    appendLogLine(logId, "[INFO] 启动命令: java -jar app.jar");
    appendLogLine(logId, "[INFO] 健康检查: http://localhost:8080/health");
    appendLogLine(logId, "[SUCCESS] 服务启动成功");
});
```

### 示例3：数据同步任务

```java
String logId = createLog(params);

// 步骤1：数据准备
logStep(logId, "数据准备", () -> {
    appendLogLine(logId, "[INFO] 查询源数据库...");
    appendLogLine(logId, "[INFO] 查询到: 5000条记录");
});

// 步骤2：数据同步
logStep(logId, "数据同步", () -> {
    for (int i = 1; i <= 10; i++) {
        appendLogLine(logId, String.format("[INFO] 批次 %d/10 同步中...", i));
        appendLogLine(logId, String.format("[INFO] 已处理: %d/5000 条", i * 500));
    }
});

// 步骤3：验证
logStep(logId, "数据验证", () -> {
    appendLogLine(logId, "[INFO] 验证数据完整性...");
    appendLogLine(logId, "[SUCCESS] 验证通过");
});
```

## 🔍 查看日志

### 查看完整日志
```java
String fullLog = getFullContent(logId);
System.out.println(fullLog);
```

### 查看某个步骤的日志
```java
// 假设步骤2的日志在第10-20行
List<Map<String, Object>> step2Logs = getLogByLineRange(logId, 10, 20);
step2Logs.forEach(line -> {
    System.out.println("行" + line.get("lineNumber") + ": " + line.get("content"));
});
```

### 查看最后N行（类似tail）
```java
Integer totalLines = getTotalLines(logId);
List<Map<String, Object>> lastLines = getLogByLineRange(logId, 
    Math.max(1, totalLines - N + 1), totalLines);
```

## 🎯 实际应用场景

### 1. CI/CD构建日志
- 申请运行环境
- 清理工作区
- 克隆代码
- 安装依赖
- 运行测试
- 构建产物
- 上传制品

### 2. 应用部署日志
- 备份当前版本
- 停止服务
- 部署新版本
- 启动服务
- 健康检查
- 回滚（如果失败）

### 3. 数据迁移日志
- 数据准备
- 数据导出
- 数据转换
- 数据导入
- 数据验证
- 清理临时数据

### 4. 批处理任务日志
- 任务初始化
- 数据查询
- 数据处理
- 结果保存
- 发送通知
- 任务完成

## 💡 最佳实践

1. **步骤命名清晰** - 使用有意义的步骤名称
2. **记录关键信息** - 记录每个步骤的关键操作和结果
3. **错误处理** - 记录错误信息，便于排查问题
4. **时间戳** - 使用autoTimestamp自动添加时间戳
5. **步骤分隔** - 使用分隔符区分不同步骤
