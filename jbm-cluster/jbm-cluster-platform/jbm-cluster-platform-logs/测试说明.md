# 业务日志功能测试说明

## 功能概述

业务日志模块支持**两种模式**的日志记录：

### 模式一：从本地日志文件读取并上传
适用于已有的日志文件需要归档到系统中的场景，例如：
- 编译日志文件
- 应用运行日志文件
- 构建日志文件
- 其他第三方系统生成的日志文件

### 模式二：业务代码直接实时写日志
适用于业务流程执行过程中实时记录日志的场景，例如：
- 订单处理流程日志
- 数据同步任务日志
- 批处理任务日志
- 接口调用链路日志

### 方式3：使用API接口测试

#### 创建日志（上传文件内容）

```bash
curl -X POST http://localhost:8080/businessLog/create \
  -H "Content-Type: application/json" \
  -d '{
    "module": "构建系统",
    "operation": "Maven编译",
    "userId": "jenkins",
    "username": "Jenkins构建机器人",
    "content": "[INFO] Building project...\n[INFO] Compiling sources...\n[INFO] BUILD SUCCESS",
    "autoTimestamp": false,
    "expireDays": 90,
    "remark": "从本地文件上传"
  }'
```

响应：
```json
{
  "code": 0,
  "success": true,
  "message": "创建业务日志成功",
  "result": {
    "logId": "a1b2c3d4e5f6g7h8"
  }
}
```

#### 追加日志（实时写入）

```bash
curl -X POST http://localhost:8080/businessLog/append \
  -H "Content-Type: application/json" \
  -d '{
    "logId": "a1b2c3d4e5f6g7h8",
    "content": "[INFO] Running tests...\n[INFO] Tests passed",
    "autoTimestamp": true
  }'
```

#### 查询日志（完整文件格式）

```bash
curl http://localhost:8080/businessLog/getFullContent/a1b2c3d4e5f6g7h8
```

#### 查询日志（按行号范围）

```bash
# 查询最后10行（类似 tail -n 10）
curl "http://localhost:8080/businessLog/getByLineRange/a1b2c3d4e5f6g7h8?startLine=1&endLine=-1" \
  | jq '.result[-10:]'

# 查询第1-5行
curl "http://localhost:8080/businessLog/getByLineRange/a1b2c3d4e5f6g7h8?startLine=1&endLine=5"
```

#### 获取总行数

```bash
curl http://localhost:8080/businessLog/getTotalLines/a1b2c3d4e5f6g7h8
```

## 测试场景说明

### 模式一测试场景

#### 场景1：上传完整的编译日志文件
模拟从Jenkins或本地读取Maven编译日志文件并上传到系统。

**代码示例：**
```java
// 读取本地日志文件
String fileContent = FileUtil.readUtf8String("/path/to/compile.log");

// 创建业务日志
CreateBusinessLogForm createForm = new CreateBusinessLogForm();
createForm.setModule("构建系统");
createForm.setOperation("Maven编译");
createForm.setContent(fileContent);
createForm.setAutoTimestamp(false); // 文件本身已有时间戳
createForm.setExpireDays(90);

String logId = businessLogService.createLog(createForm);
```

#### 场景2：上传应用运行日志文件
模拟定期归档应用运行日志（如Tomcat日志、Spring Boot日志）。

**代码示例：**
```java
// 读取最后1000行
List<String> lines = FileUtil.readUtf8Lines("/app/logs/application.log");
int startLine = Math.max(0, lines.size() - 1000);
List<String> last1000Lines = lines.subList(startLine, lines.size());
String content = String.join("\n", last1000Lines);

// 上传到系统
CreateBusinessLogForm createForm = new CreateBusinessLogForm();
createForm.setModule("应用日志");
createForm.setOperation("日志归档");
createForm.setContent(content);
createForm.setExpireDays(30);

String logId = businessLogService.createLog(createForm);
```

#### 场景3：增量上传日志（tail -f效果）
模拟实时监控日志文件，有新内容就追加上传。

**代码示例：**
```java
// 1. 创建初始日志
CreateBusinessLogForm createForm = new CreateBusinessLogForm();
createForm.setModule("实时日志监控");
createForm.setOperation("增量上传");
createForm.setContent("开始监控日志文件");
String logId = businessLogService.createLog(createForm);

// 2. 监控文件变化，有新内容就追加
while (监控文件) {
    String newContent = 读取新增的内容();
    if (hasNewContent) {
        AppendBusinessLogForm appendForm = new AppendBusinessLogForm();
        appendForm.setLogId(logId);
        appendForm.setContent(newContent);
        businessLogService.appendLog(appendForm);
    }
    Thread.sleep(1000);
}
```

### 模式二测试场景

#### 场景1：订单处理流程实时日志
在订单处理的每个步骤都实时记录日志。

**代码示例：**
```java
// 业务开始时创建日志
CreateBusinessLogForm createForm = new CreateBusinessLogForm();
createForm.setModule("订单系统");
createForm.setOperation("订单处理");
createForm.setContent("开始处理订单: " + orderId);
String logId = businessLogService.createLog(createForm);

// 每个业务步骤追加日志
AppendBusinessLogForm appendForm = new AppendBusinessLogForm();
appendForm.setLogId(logId);

// 步骤1
appendForm.setContent("验证订单信息\n验证通过");
businessLogService.appendLog(appendForm);

// 步骤2
appendForm.setContent("检查库存\n库存充足");
businessLogService.appendLog(appendForm);

// 步骤3
appendForm.setContent("调用支付\n支付成功");
businessLogService.appendLog(appendForm);

// ... 后续步骤
```

#### 场景2：数据同步任务实时日志
在数据同步过程中实时记录进度。

**代码示例：**
```java
// 创建同步任务日志
CreateBusinessLogForm createForm = new CreateBusinessLogForm();
createForm.setModule("数据同步");
createForm.setOperation("用户数据同步");
createForm.setContent("开始同步用户数据");
String logId = businessLogService.createLog(createForm);

AppendBusinessLogForm appendForm = new AppendBusinessLogForm();
appendForm.setLogId(logId);

// 分批同步，每批记录一次
for (int i = 1; i <= batches; i++) {
    // 执行同步
    syncBatch(i);
    
    // 记录进度
    appendForm.setContent(String.format(
        "批次 %d/%d 同步完成\n已处理: %d/%d 条\n进度: %d%%",
        i, batches, processed, total, progress
    ));
    businessLogService.appendLog(appendForm);
}
```

#### 场景3：批处理任务实时日志
在批处理任务执行过程中记录每个阶段。

**代码示例：**
```java
// 创建批处理日志
CreateBusinessLogForm createForm = new CreateBusinessLogForm();
createForm.setModule("批处理系统");
createForm.setOperation("账单生成");
createForm.setContent("开始生成月度账单");

AppendBusinessLogForm appendForm = new AppendBusinessLogForm();
appendForm.setLogId(logId);

// 阶段1
appendForm.setContent("数据准备阶段\n查询到: 1230个用户");
businessLogService.appendLog(appendForm);

// 阶段2
appendForm.setContent("计算账单中...\n已生成: 615份");
businessLogService.appendLog(appendForm);

// 阶段3
appendForm.setContent("发送通知\n发送完成");
businessLogService.appendLog(appendForm);
```

## 实际应用场景

### 1. CI/CD集成
```java
// Jenkins Pipeline 中调用
def logId = createBuildLog("开始构建项目")
try {
    appendLog(logId, "执行 mvn clean install")
    sh 'mvn clean install'
    appendLog(logId, "构建成功")
} catch (e) {
    appendLog(logId, "构建失败: " + e.message)
    throw e
}
```

### 2. 定时任务日志
```java
@Scheduled(cron = "0 0 2 * * ?")
public void syncDataTask() {
    String logId = businessLogService.createLog(createForm("数据同步任务"));
    try {
        // 执行同步
        appendLog(logId, "同步完成");
    } catch (Exception e) {
        appendLog(logId, "同步失败: " + e.getMessage());
    }
}
```

### 3. 微服务调用链路
```java
// 在每个微服务中传递logId
@PostMapping("/order/create")
public Result createOrder(@RequestHeader("X-Log-Id") String logId) {
    appendLog(logId, "订单服务：开始创建订单");
    // 业务逻辑
    appendLog(logId, "订单服务：创建完成");
}
```

## 注意事项

1. **文件大小限制**：单次上传建议不超过10MB，大文件建议分批上传
2. **行数限制**：单个日志建议不超过10000行，超过建议分割为多个日志
3. **过期时间**：根据业务重要性设置合理的过期时间
   - 编译日志：90天
   - 应用日志：30天
   - 实时监控日志：7天
4. **自动时间戳**：
   - 本地文件上传：建议关闭（文件本身有时间戳）
   - 实时写日志：建议开启（方便查看时间）

## 查询日志技巧

### 查看最后N行（类似tail）
```java
Integer totalLines = businessLogService.getLogTotalLines(logId);
List<BusinessLog> lastN = businessLogService.getLogByLineRange(logId, 
    Math.max(1, totalLines - N + 1), totalLines);
```

### 查看前N行（类似head）
```java
List<BusinessLog> firstN = businessLogService.getLogByLineRange(logId, 1, N);
```

### 查看中间部分
```java
List<BusinessLog> middle = businessLogService.getLogByLineRange(logId, 100, 200);
```

### 搜索关键词
```java
BusinessLogForm form = new BusinessLogForm();
form.setLogId(logId);
form.setKeyword("ERROR"); // 搜索包含ERROR的日志
DataPaging<BusinessLog> result = businessLogService.queryLogs(form);
```

## 性能优化建议

1. **批量追加**：多行内容一次性追加，而不是逐行追加
2. **异步处理**：对于非关键日志，可以异步追加
3. **定期清理**：利用自动清理功能，避免日志堆积
4. **合理分页**：查询时使用分页，避免一次加载过多数据
