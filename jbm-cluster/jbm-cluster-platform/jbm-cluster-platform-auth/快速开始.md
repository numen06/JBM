## 🚀 快速测试

### 方法 1: 使用演示页面（推荐）

1. **启动应用**
   ```bash
   # 启动认证服务
   cd jbm-cluster-platform-auth
   mvn spring-boot:run
   ```

2. **访问演示页面**
   ```
   http://localhost:8080/oauth2/demo
   ```

3. **配置参数**（使用默认值即可测试）
   - 授权服务器地址: `http://localhost:8080/oauth2/authorize`
   - 客户端 ID: `test_client`
   - 回调地址: `http://localhost:3000/callback`
   - 权限范围: `user profile`
   - State: 自动生成

4. **点击"发起 OAuth2 授权请求"**

5. **在登录页面输入凭证**
   - 用户名: `admin` (根据您的系统配置)
   - 密码: `******`

6. **确认授权**
   - 点击"允许"按钮

7. **获取授权码**
   - 系统会跳转回演示页面并显示授权码

### 方法 2: 直接访问授权端点

1. **在浏览器中访问**
   ```
   http://localhost:8080/oauth2/authorize?response_type=code&client_id=test_client&redirect_uri=http://localhost:3000/callback&scope=user&state=random123
   ```

2. **您会看到登录页面**（如果未登录）

3. **输入用户名和密码**

4. **确认授权**

5. **获取授权码**
   ```
   重定向到: http://localhost:3000/callback?code=xxxxx&state=random123
   ```

## 🔧 配置说明

### Thymeleaf 配置

确保 `application.yml` 或 `bootstrap.yml` 中有以下配置：

```yaml
spring:
  thymeleaf:
    mode: HTML
    encoding: UTF-8
    cache: false  # 开发环境设置为 false，生产环境设置为 true
    prefix: classpath:/templates/
    suffix: .html
```

### OAuth2 客户端配置

在您的 Sa-Token OAuth2 配置中注册客户端：

```java
@Configuration
public class SaTokenConfigure {
    @Bean
    public SaOAuth2Config oauth2Config() {
        SaOAuth2Config config = new SaOAuth2Config();
        
        // 配置 OAuth2 相关参数
        config.setAllowUrl("/oauth2/*");
        
        // 配置客户端（示例）
        config.setIsCode(true);  // 开启授权码模式
        config.setIsImplicit(false);
        config.setIsPassword(false);
        
        return config;
    }
}
```

## 🎯 核心改动

### 架构说明

- **LoginController** (`@Controller`): 负责页面跳转和视图渲染
- **OAuth2ServerController** (`@RestController`): 负责 OAuth2 API 和业务逻辑

### 1. LoginController.java（新增页面跳转）

**添加登录状态检查**
```java
@Controller  // 注意：使用 @Controller 而不是 @RestController
@GetMapping("/oauth2/authorize")
public String authorize(...) {
    // 检查用户是否已登录
    if (!StpUtil.isLogin()) {
        return "oauth2_login";  // 显示登录页面
    }
    return "oauth2_authorize";  // 显示授权页面
}
```

**添加演示页面**
```java
@GetMapping("/oauth2/demo")
public String demoPage() {
    return "oauth2_client_demo";
}
```

### 2. OAuth2ServerController.java（API 端点）

**处理登录请求（返回 JSON）**
```java
@RestController  // 注意：使用 @RestController
@PostMapping("/doLogin")
public ResultBody<?> doLogin(AuthorizeForm authorizeForm) {
    // 验证用户凭证
    ResultBody<JbmLoginUser> loginResult = sysLoginService.login(...);
    
    if (!loginResult.getSuccess()) {
        return ResultBody.failed().msg(loginResult.getMessage());
    }
    
    // 返回重定向URL给前端（JSON格式）
    String redirectUrl = "/oauth2/authorize?...";
    return ResultBody.ok(redirectUrl).msg("登录成功");
}
```

## 🐛 故障排除

### 问题 1: 页面无法访问
**解决方案**: 检查 Thymeleaf 是否正确配置，templates 目录是否正确。

### 问题 2: 登录后没有跳转
**解决方案**: 检查 `doLogin` 方法是否正确返回重定向，以及 OAuth2 参数是否正确传递。

### 问题 3: State 验证失败
**解决方案**: 确保 state 参数在整个流程中正确传递，不要在中途丢失。

### 问题 4: 客户端 ID 未找到
**解决方案**: 确保 OAuth2 客户端已在系统中正确注册。
