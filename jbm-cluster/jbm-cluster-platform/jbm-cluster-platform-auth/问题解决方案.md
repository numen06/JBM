# OAuth2 登录页面 - 问题解决方案

## ❌ 遇到的问题

### 错误信息
```json
{
  "code": 1000,
  "exception": "No handler found for GET /oauth2_login",
  "message": "接口异常!",
  "success": false,
  "timestamp": 1761235588066
}
```

## 🔍 问题分析

### 根本原因
**缺少 Thymeleaf 模板引擎依赖**！

当 Spring MVC Controller 返回字符串时：
- ✅ **有 Thymeleaf**: 字符串被解析为模板名称，渲染对应的 HTML 页面
- ❌ **无 Thymeleaf**: 字符串被当作重定向 URL，导致 404 错误

```java
// LoginController 返回 "oauth2_login"
return "oauth2_login";  

// 无 Thymeleaf → 系统尝试访问 /oauth2_login 路径 → 404
// 有 Thymeleaf → 渲染 templates/oauth2_login.html → ✅
```

## ✅ 已完成的修复

### 1. 添加 Thymeleaf 依赖

**文件**: `pom.xml`

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-thymeleaf</artifactId>
</dependency>
```

### 2. 添加 Thymeleaf 配置

**文件**: `bootstrap.yml`

```yaml
spring:
  thymeleaf:
    enabled: true
    mode: HTML
    encoding: UTF-8
    cache: false
    prefix: classpath:/templates/
    suffix: .html
    check-template: true
    check-template-location: true
```

### 3. 创建 Thymeleaf 配置类（重要！）

**文件**: `ThymeleafConfig.java`

这个配置类确保 Thymeleaf 视图解析器优先级高于默认的 JSP 解析器：

```java
@Configuration
public class ThymeleafConfig implements WebMvcConfigurer {
    
    @Bean
    public ViewResolver thymeleafViewResolver() {
        ThymeleafViewResolver resolver = new ThymeleafViewResolver();
        resolver.setTemplateEngine(templateEngine());
        resolver.setCharacterEncoding("UTF-8");
        resolver.setOrder(0);  // 最高优先级
        return resolver;
    }
    
    // ... 其他配置方法
}
```

**为什么需要这个配置类？**
- Spring Boot 默认可能会同时注册 JSP 和 Thymeleaf 视图解析器
- 如果 JSP 解析器优先级更高，会导致模板名称被当作 JSP 路径处理
- 通过设置 `order=0`，确保 Thymeleaf 最先处理视图名称

### 4. 修复路径配置

**文件**: `LoginController.java`

```java
@Controller  // 不是 @RestController
@Api(tags = "登录页面")
public class LoginController {  // 移除了 @RequestMapping("/")

    @GetMapping("/oauth2/authorize")  // 恢复正确的 OAuth2 路径
    public String authorize(...) {
        if (!StpUtil.isLogin()) {
            return "oauth2_login";      // 返回模板名称
        }
        return "oauth2_authorize";
    }
}
```

## 🔧 其他可能的问题

### 问题 1: 端口冲突

**错误**: `Port 5555 is already in use`

**解决**:
```bash
# 查找占用端口的进程
lsof -ti:5555

# 杀死进程
kill -9 <PID>
```

### 问题 2: 模板文件未找到

**错误**: `Template might not exist or might not be accessible`

**检查**:
1. 确保文件路径正确：`src/main/resources/templates/oauth2_login.html`
2. 确保文件名正确（区分大小写）
3. 重新构建项目

### 问题 3: Thymeleaf 缓存问题

**问题**: 修改模板后页面没有更新

**解决**:
```yaml
# bootstrap.yml 中设置
spring:
  thymeleaf:
    cache: false  # 开发环境关闭缓存
```

### 问题 4: Maven 依赖未下载

**检查**:
```bash
# 查看 Maven 仓库
ls ~/.m2/repository/org/springframework/boot/spring-boot-starter-thymeleaf/

# 如果为空，手动下载
mvn dependency:resolve
```
