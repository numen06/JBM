# OAuth2 登录页面更新日志

## 2025-10-23 架构调整

### 问题描述
原先 `OAuth2ServerController` 使用 `@RestController` 注解，导致无法正确返回页面视图，所有返回值都被序列化为 JSON。

### 解决方案
将页面跳转相关的方法从 `OAuth2ServerController` 转移到 `LoginController`，实现职责分离。

### 修改内容

#### 1. LoginController.java（新增方法）

**新增方法：**

1. **authorize()** - OAuth2 授权页面
   - 路径：`GET /oauth2/authorize`
   - 功能：检查用户登录状态
     - 未登录 → 显示 `oauth2_login.html` 登录页面
     - 已登录 → 显示 `oauth2_authorize.html` 授权确认页面
   - 参数：response_type, client_id, redirect_uri, scope, state

2. **demoPage()** - OAuth2 客户端演示页面
   - 路径：`GET /oauth2/demo`
   - 功能：显示 OAuth2 客户端演示页面
   - 返回：`oauth2_client_demo.html`

**注解：**
- `@Controller` - 支持返回视图名称
- `@Api(tags = "登录页面")` - Swagger 文档分组

#### 2. OAuth2ServerController.java（移除和修改）

**移除方法：**
- ~~`authorize()`~~ - 已移至 LoginController
- ~~`demoPage()`~~ - 已移至 LoginController

**修改方法：**
- `doLogin()` - 改为返回 JSON 响应
  - 旧实现：使用 `response.sendRedirect()` 进行服务器端重定向
  - 新实现：返回 `ResultBody<?>` 包含重定向 URL
  - 前端接收后自行跳转

**注解保持：**
- `@RestController` - 所有方法返回 JSON

#### 3. oauth2_login.html（前端调整）

**修改登录逻辑：**
- 旧逻辑：表单提交后依赖服务器重定向
- 新逻辑：AJAX 提交，接收 JSON 响应，前端 JavaScript 处理跳转

```javascript
// 接收后端返回的 JSON
const result = await response.json();

if (result.success || result.code === 200) {
    // 使用后端返回的重定向URL
    const redirectUrl = result.result || result.data;
    window.location.href = redirectUrl;
}
```

### 架构优势

#### 1. 职责分离
- **LoginController**: 负责页面跳转和视图渲染
- **OAuth2ServerController**: 负责 OAuth2 API 和业务逻辑

#### 2. 一致的 API 风格
- `@RestController` 所有方法统一返回 JSON
- `@Controller` 所有方法统一返回视图

#### 3. 前后端分离友好
- 后端返回标准 JSON 响应
- 前端控制页面跳转逻辑
- 便于后续前后端完全分离

### API 端点变化

#### 保持不变的端点：
- `GET /oauth2/authorize` - 仍然可以访问（现在由 LoginController 处理）
- `GET /oauth2/demo` - 仍然可以访问（现在由 LoginController 处理）
- `POST /oauth2/doLogin` - 路径不变，但返回格式改为 JSON

#### 响应格式变化：

**旧格式（服务器端重定向）：**
```
HTTP/1.1 302 Found
Location: /oauth2/authorize?response_type=code&...
```

**新格式（JSON 响应）：**
```json
{
  "code": 200,
  "success": true,
  "message": "登录成功",
  "result": "/oauth2/authorize?response_type=code&client_id=xxx&...",
  "timestamp": "2025-10-23T10:30:00"
}
```

### 开发者注意事项

#### 添加新的页面端点时：
1. 页面跳转方法应该放在 `LoginController` 中
2. 使用 `@Controller` 而不是 `@RestController`
3. 方法返回类型为 `String`（视图名称）

#### 添加新的 API 端点时：
1. API 方法应该放在 `OAuth2ServerController` 或其他 RestController 中
2. 使用 `@RestController`
3. 方法返回类型为 `ResultBody<?>` 或其他数据对象

### 问题排查

#### 问题 1：页面无法显示，返回 JSON
**原因**：方法在 RestController 中
**解决**：将方法移至 Controller 类中

#### 问题 2：登录后没有跳转
**原因**：前端没有正确处理 JSON 响应
**解决**：检查 JavaScript 代码，确保读取 `result.result` 或 `result.data`

#### 问题 3：OAuth2 参数丢失
**原因**：表单中缺少隐藏字段
**解决**：确保所有 OAuth2 参数都作为隐藏字段传递
