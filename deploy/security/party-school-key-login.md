# 党校密钥登录配置

`party-school-key-login.json` 是党校认证服务的环境配置增量，合入党校 Nacos 的 `jbm-py / DEFAULT_GROUP / auth-prod.yml`，只调整 `jbm.auth.key-login` 下列出的四个字段，保留其他配置。变更前备份原文，比较当前版本后提交，再回读核对并重启认证服务。

认证镜像升级与环境配置独立：本地 `auth-dev.yml` 中开启密钥登录，不会启用党校生产配置。发布验收须同时核对运行代码、有效配置，以及公网 `/jbm-api/auth/oauth2/keys/login-options` 的文件密钥挑战响应；仅前端入口可见或容器健康不足以证明功能已启用。

党校只接受 `jxdx.project.hz-aitech.com` 及对应 HTTPS 来源，不复用本地调试域名。保留现有密码校验、PKCE、权限、密钥撤销和挑战一次性校验。首次生成需要验证当前账号密码；用户明确授权时，可通过正式接口生成并保存在用户本地。公网挑战成功与实际文件登录成功分别记录。

后续其他系统复用同一套 JBM 密码登录与密钥文件登录流程，分别配置所属平台域名。运维登录优先使用本地有效密钥，无有效密钥时才使用已有密码生成。按域名和账号保存到当前用户的 `Documents/JBM登录密钥`，私钥不上传服务器、不提交 Git；验收须重新读取已保存文件完成 OAuth/PKCE 登录，并核对账号和权限。
