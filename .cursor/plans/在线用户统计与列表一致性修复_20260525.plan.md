## 统一规则

### 1. 唯一事实来源

在线用户事实来源统一为 Redis：

```text
online_tokens:{token}
```

原因：

- Auth 登录监听器写入这个表。
- 在线用户列表已经读取这个表。
- 分布式 Auth/Center/Gateway 模式下，Center 本地 `StpUtil.searchTokenValue` 不应作为统计唯一来源。

### 2. 有效在线记录判断

统计和列表必须使用同一套判断：

- key 匹配 `online_tokens:*`
- `redisService.getCacheObject(key)` 返回 `SysUserOnline` 非空
- `redisService.getExpire(key) > 0`
- 如果额外校验 Sa-Token/OAuth access token，则统计和列表都必须同样校验

无效记录处理：

- 列表不展示。
- 统计不计数。
- 可选：发现对象为空或 TTL <= 0 时删除该 key。

### 3. total 语义

`/online/pageList`：

- 无搜索条件：`total = 有效在线记录总数`
- 有 `ipaddr/userName` 搜索：`total = 搜索过滤后的有效在线记录总数`
- `contents = 当前页数据`

`/user/statistics.onlineUser`：

- 始终返回全量有效在线用户数。
- 不受在线用户列表搜索条件影响。
- 在无搜索条件时应等于 `/online/pageList.total`。

## 修复建议

### 1. 抽取共享服务

建议新增或复用一个服务，例如：

```text
OnlineUserQueryService
```

放置位置可选：

- `jbm-cluster-platform-auth` 如果只给 Auth 用。
- 更推荐公共模块或 Center 可引用位置，因为 Center 的 `/user/statistics` 也需要相同逻辑。

如果短期不想新增模块，可以先在 Center 也用 `RedisService + JbmCacheConstants.ONLINE_TOKEN_KEY` 实现相同逻辑，但要避免两份代码长期分叉。

建议方法：

```java
List<SysUserOnline> listValidOnlineUsers()
long countValidOnlineUsers()
```

列表接口基于 `listValidOnlineUsers()` 做搜索过滤和分页。

统计接口基于 `countValidOnlineUsers()`。

### 2. 修复 `/user/statistics`

目标：

```java
stats.setOnlineUser(onlineUserQueryService.countValidOnlineUsers());
```

或短期：

```java
Collection<String> keys = redisService.keys(JbmCacheConstants.ONLINE_TOKEN_KEY + "*");
long count = keys.stream()
    .filter(key -> redisService.getExpire(key) > 0)
    .filter(key -> redisService.getCacheObject(key) != null)
    .count();
stats.setOnlineUser(count);
```

不要再使用 Center 本地 `StpUtil.searchTokenValue` 作为在线人数统计。

### 3. 修复 `/online/pageList`

目标：

- 先拿有效在线记录。
- 再应用搜索过滤。
- 再 `total = filteredList.size()`。
- 最后分页。

注意：

- `removeAll(Collections.singleton(null))` 应在 total 计算前完成。
- 已过期或对象为空的记录不进入 total。
- 排序应稳定，建议按 `loginTime desc` 或 `activityTime desc`。

### 4. 前端处理

前端原则：

- 仪表盘显示 `/user/statistics.onlineUser`。
- 在线用户列表显示 `/online/pageList.total`。
- 无搜索条件时两个值应一致。
- 有搜索条件时列表 total 可以小于仪表盘统计，这是正常语义。

如页面有搜索条件，建议显示“筛选结果 N / 当前在线 M”，避免用户误解。

## 总测阶段验收

以下由总体验证任务统一执行：

1. 重启 Auth/Center/Gateway/前端。
2. 登录管理员 `admin`。
3. 再登录一个普通用户或开发者用户，保持两个会话不退出。
4. 调 `/user/statistics`：
   - `onlineUser >= 2`
5. 调 `/online/pageList` 无搜索：
   - `total == statistics.onlineUser`
   - 列表行包含 admin 和普通用户。
6. 在在线用户页面搜索 `admin`：
   - 列表 total 变成过滤后数量。
   - 仪表盘在线总数不变。
7. 注销或踢出一个用户：
   - `/online/pageList.total` 减少。
   - `/user/statistics.onlineUser` 同步减少。
8. 等待或模拟 token 过期：
   - 过期会话不在列表。
   - 过期会话不计入统计。
