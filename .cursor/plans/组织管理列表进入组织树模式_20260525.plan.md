日期：2026-05-25  
根目录：`D:\workspaces\JBM7`

## 问题结论

用户反馈：组织管理应该体现“从列表进入组织树”的模式，目前没有体现。

当前判断：确认是产品体验和功能结构缺口。

现状：

- `OrgList.vue` 是分页表格为主。
- 父级组织在新建/编辑里是手填 `parentId` 数字。
- 页面描述里虽然写了“树结构通过 /baseOrg/tree 供选择器使用”，但组织管理主页面没有真正的树管理体验。
- `useOrgTree.ts` 已有 `listOrgTree()` 和 `flattenOrgs()` 能力，但主要被 `OrgTreeSelect.vue` 消费。
- 后端已有 `/baseOrg/tree`、`/baseOrg/pageList`、`/baseOrg/save`、`/baseOrg/delete`，具备改造基础。

## 目标体验

组织管理首页应是“树优先”的管理界面，而不是单纯分页表格。

建议布局：

```text
┌─────────────────────────────────────────────────────────┐
│ 组织管理                         [树视图] [列表视图] [刷新] [新建根组织] │
├───────────────┬─────────────────────────────────────────┤
│ 左侧组织树     │ 右侧详情区                                │
│ 搜索组织       │ 选中组织：默认组织                          │
│ 默认组织       │ 基本信息 / 直属子组织 / 操作                  │
│ ├─ 研发部      │ [新建子组织] [编辑] [删除]                    │
│ └─ 运营部      │ 子组织表格：名称、编码、排序、状态、操作          │
└───────────────┴─────────────────────────────────────────┘
```

核心交互：

- 左侧展示完整组织树。
- 点击节点后，右侧显示该组织详情。
- 右侧展示该组织的直属子组织。
- “新建子组织”自动带上当前选中节点作为 `parentId`。
- “新建根组织”用于创建无父级组织。
- 编辑组织时父级选择使用树选择器，不再手填 ID。
- 列表视图作为辅助入口，用于搜索和分页维护全部组织。

## 具体建议

### 1. 增加树视图和列表视图切换

用 tabs 或 segmented control：

- `组织树`
- `列表`

默认进入 `组织树`。

列表视图保留现有分页、搜索、编辑能力，作为批量查找和兜底管理。

### 2. 实现组织树组件

可以先在 `OrgList.vue` 内实现，不一定抽独立组件。

树节点需要：

- 组织名称。
- 状态标识。
- 子节点数量可选。
- 当前选中高亮。
- 展开/折叠。
- 搜索过滤或搜索后高亮。

注意：不要把树只做成 `<select>`，组织管理主页面必须真实展示树。

### 3. 右侧详情区

选中组织后显示：

- 组织 ID
- 组织名称
- 组织编码
- 父级组织
- 排序
- 状态
- 所属层级或路径，可选

操作：

- 新建子组织
- 编辑当前组织
- 删除当前组织

删除要求：

- 如果存在子组织，需明确阻止或二次确认。
- 根组织或默认组织如果是系统保留数据，不允许删除。

### 4. 子组织列表

右侧显示当前节点的直属子组织：

- 名称
- 编码
- 状态
- 排序
- 操作

这里可以直接从树数据里的 `children` 渲染，不必额外请求。

### 5. 新建/编辑弹窗

当前弹窗：

```text
父级 ID：Input type=number
```

需要改为：

- 父级组织：`OrgTreeSelect`
- 新建子组织时默认选中当前节点，且可禁用或允许调整。
- 根组织允许为空。

保存时：

- `parentId` 从树选择器来。
- 不再要求用户知道数字 ID。

### 6. 多租户/多组织可见范围

短期遵循现有后端 `/baseOrg/tree` 返回范围。

Cursor 需要梳理：

- 平台管理员：可见全组织树。
- 租户/组织管理员：只可见自己组织范围和授权范围。
- 普通用户：不能进入组织管理。

如果当前后端 `/baseOrg/tree` 未按登录用户范围过滤，需要记录为风险或补修。

2. 进入 `/system/orgs`。

10. 编辑该组织时，父级选择是树选择器，不是手填数字 ID。

12. 组织名称不乱码。
