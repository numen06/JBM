# JBM 并行任务完成后总体验证

## 核心规则

所有子任务并行开发，只有本总测任务负责统一启动和全链路测试。

子任务禁止：

- 单独重启 Auth/Center/Gateway/前端。
- 单独执行全链路 Playwright/E2E。
- kill 不属于自己的进程。
- 清理其他任务可能正在使用的数据。

本总测任务执行前必须确认：

- 所有子任务已完成或暂停。
- 没有人正在使用同一套本地端口跑服务。
- 测试数据使用统一前缀，例如 `jbm_total_<timestamp>`。

## 统一构建

```powershell
cd D:\workspaces\JBM7\jbm-admin-vue
npm.cmd run build
```

```powershell
cd D:\workspaces\JBM7
mvn -pl jbm-cluster/jbm-cluster-api/jbm-cluster-api-basic,jbm-cluster/jbm-cluster-common/jbm-cluster-common-mysql,jbm-cluster/jbm-cluster-platform/jbm-cluster-platform-auth,jbm-cluster/jbm-cluster-platform/jbm-cluster-platform-center,jbm-cluster/jbm-cluster-platform/jbm-cluster-platform-gateway -am -DskipTests install
```

## 统一启动

只在本计划执行：

```powershell
cd D:\workspaces\JBM7
python scripts\jbm_cluster_ops.py restart
```

## 统一页面实测范围

- 注册登录：从 `/register` 到 `/login` 到 `/dashboard`。
- 开发者接入：申请开发者、管理员审批、创建 API Key。
- 在线用户：菜单出现、仪表盘数量正确、列表看到当前会话。
- 组织管理：新建中文组织，刷新、接口、数据库均不乱码。
- 菜单管理：分页、搜索、平台菜单/应用菜单范围、平台菜单保护。
- 字段管理：点击字段组后右侧显示字段定义。
- 网关管理：路由、限流、IP 限制新增、筛选、编辑、删除。
- 多租户/应用隔离：不同组织/应用下菜单、字段、API Key、网关策略不可串数据。
